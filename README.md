# 🍽️ GastroFlow — SaaS Gastronómico B2B

GastroFlow es una solución full-stack moderna diseñada para optimizar la gestión operativa de restaurantes. Permite conectar en tiempo real el menú digital del comensal (QR) con la pantalla de pedidos para cocina (KDS) y el panel de métricas del negocio.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** Next.js (App Router), React, Tailwind CSS, Lucide Icons
- **Backend & Base de Datos:** Supabase (PostgreSQL)
- **Lenguaje:** TypeScript

---

## 🚀 Características Principales

- 📊 **Dashboard de Operaciones:** Visualización de ventas, mesas ocupadas y pedidos activos.
- 👨‍🍳 **Sistema KDS (Kitchen Display System):** Flujo de comandas en tiempo real para cocina.
- 📱 **Menú QR Interactivo:** Consulta de platos y precios sincronizados con la base de datos.
- 🗄️ **Persistencia en la Nube:** Estructura relacional administrada en Supabase.
